# Keyboard Shortcuts

Lumina is designed to be highly keyboard-accessible. Here is a comprehensive list of all the keyboard shortcuts available.

---

## Global & Vault Actions

| Shortcut | Action |
|----------|--------|
| `Ctrl + Space` | **Spotlight / Command Palette** — Open the search & AI bar from anywhere |
| `Ctrl + P` | Quick Switcher / Note Palette |
| `Ctrl + Shift + F` | Global Full-Text Search |
| `Ctrl + S` | Save current note |
| `Ctrl + N` | Create a new note |
| `Ctrl + R` | Rename current note |
| `Ctrl + Shift + D` | Delete current note |

---

## Editor & Markdown Formatting

| Shortcut | Action |
|----------|--------|
| `Ctrl + B` | Toggle **Bold** (`**text**`) |
| `Ctrl + I` | Toggle *Italic* (`*text*`) |
| `Ctrl + Shift + X` | Toggle ==Highlight== (`==text==`) |
| `Ctrl + Shift + C` | Toggle `Inline Code` (`` `text` ``) |
| `Ctrl + Shift + K` | Toggle [Hyperlink](url) |
| `Tab` | Indent line / list item |
| `Shift + Tab` | Unindent line / list item |
| `Alt + Up / Down` | Move current line up / down |

---

## Navigation & Panes

| Shortcut | Action |
|----------|--------|
| `Ctrl + G` | Open Knowledge Graph |
| `Ctrl + \` / `Ctrl + Shift + V` | Toggle Markdown Preview |
| `Ctrl + B` | Toggle Sidebar visibility |
| `Ctrl + Tab` | Switch to Next Tab |
| `Ctrl + Shift + Tab` | Switch to Previous Tab |
| `Ctrl + W` | Close Active Tab |
| `Ctrl + ,` | Open Settings |
| `Escape` | Close active modal, palette, or preview card |

---

## AI Features

| Shortcut | Action |
|----------|--------|
| `Ctrl + Shift + \` | Open the AI Assistant Chat panel |
| `Ctrl + K` | Open Inline AI Composer |
| `Ctrl + Space` | Spotlight Bar (Type a question and press Enter) |
